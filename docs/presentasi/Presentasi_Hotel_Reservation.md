# Outline Presentasi Sistem Reservasi Hotel

1. Judul Project
   - Nama project, anggota kelompok, dan mata kuliah.
2. Latar Belakang
   - Kebutuhan pengelolaan reservasi hotel secara terstruktur.
3. Tujuan
   - Tujuan perancangan dan implementasi database.
4. Aktor Sistem
   - Tamu, resepsionis, kasir, dan supervisor.
5. Business Rules
   - Aturan utama yang mengatur relasi data.
6. ERD
   - Penjelasan entitas, atribut, dan relasi Crow's Foot.
7. Normalisasi
   - Ringkasan UNF, 1NF, 2NF, dan 3NF.
8. Implementasi Tabel
   - Daftar tabel dan constraint utama.
9. Query
   - Contoh query sederhana, join, subquery, CTE, dan agregasi.
10. View
    - View detail reservasi tamu dan laporan pembayaran.
11. Procedure
    - Stored procedure untuk menghitung total reservasi.
12. Trigger
    - Trigger pencatatan log setelah pembayaran.
13. Function
    - Function untuk menghitung total biaya.
14. Demo
    - Alur menjalankan script SQL dan contoh hasil query.
15. Kesimpulan
    - Ringkasan hasil project dan saran pengembangan.
